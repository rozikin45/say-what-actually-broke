One line of software error copy, at most 200 characters, that tells the user the brutal truth about what went wrong and makes them laugh: the session expired because the server clock drifted 12 minutes into the future — log in again; the server should catch up with reality shortly.

## Run it

```sh
python3 main.py
```

The program writes the 144-character line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set). Deterministic: no randomness, no clock, no network, no file reads.
